# Castel Sant’Angelo — Rome

Original procedural exterior of Castel Sant’Angelo: four projecting bastions and curtain walls, broad cylindrical mausoleum drum, papal apartments, crenellated parapets and the winged bronze Saint Michael crowning the keep.
