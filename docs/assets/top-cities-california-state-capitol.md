# California State Capitol — Sacramento

Historic California State Capitol: stepped white classical wings, granite base, six-column west portico and sculptural pediment, a two-storey drum with 24 columns, ribbed dark copper dome and open gold-capped lantern.

Only historic west building OSM1569845423 and its west portico are owned; separate State Assembly/Senate eastern annex ways1444090116/117 and current construction are excluded. OSM low dome heights conflict with published street-to-ball67.04m; SGH64m/210ft is a dome-only description and secondary247ft estimates are not adopted. Main body23.8m follows NPS78ft; other intermediate levels and ornamental simplifications are photo estimates. The six west columns,24 drum columns and12 lantern columns are retained in both LODs. Original abstract pediment relief evokes Minerva group without scanned sculpture. No flags, lettering, exterior signs, surrounding paving or landscaping.

Silhouette and distinguishing features are authored individually. Facade windows partition wall faces rather than lying over backing polygons; far retains the silhouette and a separate coarser grid of window bays. Repeated elements are merged by material. Small decorative detail is simplified at map scale; the model is an exterior and has no interior-use claim.
