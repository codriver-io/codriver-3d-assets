# Jacques-Cartier · south-out island access

Mapped concrete access viaduct joining the Jacques-Cartier deck, pavilion loop and island streets.

This is a separate component of the [Jacques-Cartier bridge kit](pont-jacques-cartier.md). Download the main bridge and all four access ramps for the complete island approach. Every component shares origin `[-73.5417613, 45.5218315]`, metres and east/up/south axes; do not individually centre them when assembling the kit.

Build with `pnpm build:montreal-landmarks`. Editable source: [jacques-island-ramps.js](../../src/peregrine/landmarks/jacques-island-ramps.js). Alignment and source way IDs: [jacques-island-alignments.js](../../src/peregrine/landmarks/jacques-island-alignments.js), mapped from OpenStreetMap on 30 September 2026.

Original model: CC BY 4.0, Codriver / 9570-6198 Québec inc. Code: MIT. Geographic data © OpenStreetMap contributors, ODbL 1.0. Vertical profiles, member sizes and simplified supports are visual estimates.

Mode evidence and junction-placement requirements are recorded in the [main kit documentation](pont-jacques-cartier.md). The public viewer alone does not validate terrain integration.
