# Walton County Historic Courthouse — Monroe

Walton’s restored 1883–84 courthouse: red brick, tall round-headed courtroom windows, an open bracketed porch and balcony, steep slate mansards with pedimented dormers and circular end-gable windows, and the current flat-crowned white clock tower. The original tornado-destroyed dome is not recreated.
